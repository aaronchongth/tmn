# `tmn` (`too-many-nodes`) v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `tmn`, a single-binary ROS-agnostic Linux terminal UI wrapper that runs `ros2 launch` (or any command) in a PTY and lets users interactively filter logs by OS process, composable ROS logger, severity, and regex, holding logs in post-mortem mode on `Ctrl-C`.

**Architecture:** A synchronous multi-threaded Rust binary (`std::thread` + `std::sync::mpsc`) with zero async runtime overhead. A PTY session spawns the child in its own session (`setsid` + `TIOCSCTTY`) and streams decoded lines into an ANSI-aware `ros2 launch` / `rcutils` parser, a bounded `VecDeque` ring buffer with interned process/logger IDs, and a pure `App` reducer rendered lazily through `ratatui` + `ansi-to-tui`.

**Tech Stack:** Rust 2024 (`rustc >= 1.91`), `clap = "4.6"`, `ratatui = "0.30"`, `crossterm = "0.29"`, `ansi-to-tui = "8.0"`, `nix = "0.31"` (features: `["pty", "process", "signal", "term", "fs"]`), `regex = "1.13"`, `signal-hook = "0.3"`.

**Spec:** `docs/design.md`

## Global Constraints

- Binary & crate name: `tmn`, Rust edition `2024`, MSRV `1.91`, target platform Linux (`unix`).
- Zero ROS build/runtime dependencies (`rcl`, `rmw`, `rclpy`, `ros2cli` forbidden).
- Strict lints in `Cargo.toml`: `[lints.clippy] all = "deny"`, `unwrap_used = "deny"`, paired with `clippy.toml` (`allow-unwrap-in-tests = true`, `allow-expect-in-tests = true`) so production code forbids `unwrap()` while unit/integration tests remain ergonomic under `cargo clippy --all-targets`.
- Default `--max-lines`: `100000` (`>= 1`).
- Default child env vars (when `--no-env-override` is `false`, injected **only if unset** in caller env): `OVERRIDE_LAUNCH_PROCESS_OUTPUT=both`, `RCUTILS_COLORIZED_OUTPUT=1`, `RCUTILS_LOGGING_BUFFERED_STREAM=0`, `PYTHONUNBUFFERED=1`.
- Exit codes: bare `tmn` or invalid CLI args -> `2` (message on `stderr`); interactive clean `q` -> `0`; PTY/spawn/terminal init error -> `1`; `--headless` -> child's exit code (`128 + signal` on signal termination).
- Composable-logger UI rule: child logger sub-rows under a process appear in `source_rows()` **only when that process has `>= 2` distinct loggers**.

## Review Focus

1. **Linux PTY `EIO` + unterminated final crash line:** When the last child closes the PTY slave after writing bytes without a trailing `\n` (e.g., `"Segmentation fault"`), Linux `read()` returns `Errno::EIO`; `tmn` must flush the trailing partial line and treat `EIO` as clean EOF rather than an error. *(Tested in Task 5)*
2. **Multi-byte UTF-8 split across `read()` chunks & invalid bytes:** Splitting raw bytes on `\n` must happen *before* `String::from_utf8_lossy` so multi-byte UTF-8 spanning chunk boundaries stays intact while invalid bytes (`0xff`) become `U+FFFD` without panicking. *(Tested in Task 5)*
3. **ANSI escape codes + non-ASCII UTF-8 around `[proc-N]` (`display_offset` safety):** `display_offset` on `LogEntry` must always be a valid UTF-8 byte boundary in `raw` and preserve child SGR colors after stripping `[proc-N] `. *(Tested in Task 2)*
4. **Paused scroll stability during ring-buffer eviction:** When `follow_tail == false` and incoming spam evicts front entries from the full ring buffer, the viewport scroll anchor must compensate by the eviction delta (clamping at `0`) so the user's paused text does not drift upward on every new line. *(Tested in Task 4)*
5. **Stubborn child ignoring `SIGINT` on `q`:** Pressing `q` when a child traps and ignores `SIGINT` must escalate `SIGINT` -> `SIGTERM` -> `SIGKILL` (via timeout or repeated `q`/`Ctrl-C`) to `-child_pgid` so `tmn` neither hangs indefinitely nor leaves orphan processes. *(Tested in Task 5)*
